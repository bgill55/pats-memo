# Screenshots Directory

This directory should contain screenshots for the PWA install prompt.

## Required Files

- `screenshot-1.png` - Main recording interface (1170 x 2532)
- `screenshot-2.png` - Hands-free voice commands (1170 x 2532)
- `screenshot-3.png` - Saved memos list (1170 x 2532)

## How to Create

1. Open `scripts/generate-screenshots.html` in your browser
2. Follow the instructions to capture screenshots
3. Save them in this directory with the names above

## Quick Method

Run your app locally or on a deployed URL, then:

1. Open Chrome DevTools (F12)
2. Toggle device toolbar (Ctrl+Shift+M)
3. Set dimensions to 390 x 844 (iPhone 14 Pro)
4. Open command palette (Ctrl+Shift+P)
5. Type "Capture screenshot" and press Enter
6. Repeat for each view, save with appropriate names

The screenshots will enhance the PWA install experience!
