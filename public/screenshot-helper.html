📸Screenshot Helper

Create beautiful screenshots for your PWA install prompt

Quick Start

This will open your app in a mobile-sized window, perfect for taking screenshots!

Step-by-Step Guide

1 Open DevTools
  • Press F12 or right-click → "Inspect"
  • Toggle device toolbar: Ctrl+Shift+M (Windows) or Cmd+Shift+M (Mac)
2 Set Mobile Dimensions
  • Select "iPhone 14 Pro" from the device dropdown
  • Or set custom: 390 × 844
  • Make sure zoom is set to 100%
3 Capture 3 Screenshots
  • Screenshot 1: Main interface (show the textarea and mic button)
  • Screenshot 2: Hands-free mode (click "Hands-Free" button first)
  • Screenshot 3: Saved memos (create 2-3 demo memos first)
4 Save Screenshots
  • In DevTools, press Ctrl+Shift+P (Cmd+Shift+P on Mac)
  • Type "screenshot" and select "Capture screenshot"
  • Repeat for each view
  • Rename files to: screenshot-1.png, screenshot-2.png, screenshot-3.png
5 Add to Project
  • Move the 3 PNG files to: public/screenshots/
  • Rebuild and deploy your app
  • Screenshots will appear in the PWA install prompt! 🎉
⚠️ Tips for Best Results:
  • Use light mode for consistency
  • Add demo content - create some sample memos before screenshot 3
  • Target size: 1170 × 2532 (or 390 × 844)
  • Make sure no personal information is visible
