📸 PWA Screenshot Generator

Follow these steps to create screenshots for your PWA install prompt:

Manual Screenshot Method (Recommended)

Step 1: Open your app in a new window with mobile dimensions
Step 2: In the mobile window, capture these 3 screens:
  • Screenshot 1: Main interface (show the textarea and mic button)
  • Screenshot 2: Hands-free mode active (click "Hands-Free" button first)
  • Screenshot 3: Saved memos (create some demo memos first)
Step 3: Use browser DevTools screenshot feature:
  • Press F12 to open DevTools
  • Press Ctrl+Shift+M (Windows) or Cmd+Shift+M (Mac) for device toolbar
  • Select "iPhone 14 Pro" or set custom: 390 x 844
  • Press Ctrl+Shift+P → type "screenshot" → "Capture screenshot"
Step 4: Save screenshots:
  • Rename downloaded files to: screenshot-1.png, screenshot-2.png, screenshot-3.png
  • Move them to: public/screenshots/
⚠️ Note: Make sure to:
  • Use light mode for consistency
  • Add some demo memos before taking screenshot 3
  • Screenshot dimensions should be 1170 x 2532 (or 390 x 844)
